Назва програми:
**Система електронної черги для складання іспитів у сервісному центрі МРЕО.**

Основний функціонал:
Програма дозволяє користувачам стати в електронну чергу для складання теоретичного або практичного іспиту. Кожному користувачу генерується номерок. При обробці черги система викликає користувача й очікує підтвердження присутності протягом 5 секунд. Якщо користувач не з’являється — він автоматично записується до списку тих, хто не з’явився. У разі присутності, програма симулює складання іспиту (з випадковим результатом) та зберігає результат. Також реалізовано можливість перегляду списків тих, хто здав або не здав.

Розподіл роботи в команді:

Данило — розробка інтерфейсу користувача (меню, взаємодія з системою).

Андріан — логіка роботи черги, збереження даних у файли.

Влад — реалізація таймера, генерація та перевірка результатів іспитів.








Program Title:
**Electronic Queue System for Driving Exams in the MREO Service Center.
**
Main functionality:
The program allows users to join an electronic queue for either the theoretical or practical driving exam. Each user receives a unique ticket number. While processing the queue, the system calls a user and waits for a response within 5 seconds. If the user does not respond, they are automatically marked as absent. If they do respond, the program simulates the exam with a random result and stores it. There is also functionality to view lists of users who passed or failed.
